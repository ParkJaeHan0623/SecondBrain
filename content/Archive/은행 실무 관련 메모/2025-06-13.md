### ✅ SQL 재확인 사항

- `SELECT MAX(적용일자)` 구문 사용 시  
    → **전문버전번호 기준 비교 조건 필수**

#### 예시:

```sql
SELECT MAX(NBW_MESG_APLY_DT) AS NBW_MESG_APLY_DT
FROM CPBBO_MSGVR_L
WHERE NBW_MESG_TYCD = :tx_tp_cd
  AND NBW_MESG_VER_NO > :tx_ver_no
```

- 위 예시는 **현재보다 높은 버전들의 적용일자 중 가장 최신값**을 구함

### ✅ 논리코드 내 날짜 비교 조건 구현

- 목적: **기존보다 더 미래일자는 등록 불가**
- 적용 위치: `등록/수정 시 입력값 검증`

```java
if ([r전문적용일자조회].[전문적용일자] >= [iISO20022전문버전등록].[전문적용일자]) {
  code = "9999";
  params = "기존 버전보다 빠른 적용일자만 등록 가능합니다.";
  return;
}
```

### ✅ 적용일자 검증 로직 이중 처리 여부 검토

- 현재 조건:  
    → **기존 버전(하위)보다 더 미래일자 등록 방지**
- 검토 항목:
    - 반대 방향의 조건도 필요함
        - 상위 버전이 **기존보다 과거 적용일자를 갖는 경우 방지**
- 결론:  
    → **상/하위 버전 모두 적용일자 범위 체크 필요**
