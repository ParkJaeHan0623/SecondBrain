## 🧭 RSA에서 OP 위치 찾는 절차 (실무 루트)

### 🔹 1. DevOn에서 시작

- 경로: `DevOn → 서비스관리 → 서비스파라미터관리`
- **서비스 ID 검색**: `BBO04892021` 입력
- **서비스 구현 클래스 및 메소드** 확인

### 🔹 2. 구현 클래스 끝부분에서 `pbc` 복사

- 예: `jbb.pic.pbc.bbo.거래코드관리Pbc`
- 클래스명 끝에 붙은 `Pbc`는 **Controller 역할**로 봐도 됨

### 🔹 3. RSA에서 Ctrl + H 검색

1. RSA 열기
2. `Ctrl + H` → 자바 자원 검색창 호출
3. **옵션 설정**:
    - 자바 검색 범위: 한계 없음
    - 모든 발생(All Occurrence) 체크
4. 복사해온 `Pbc` 클래스명 붙여넣기 → 검색

### 🔹 4.검색 결과에서 메소드 추적

- 결과창에서 메소드명 우클릭 → **"코드 2 모델(Code2Model)"** 클릭  
    → 해당 메소드와 연결된 **OP / ACSD / 논리코드 등으로 자동 이동**
