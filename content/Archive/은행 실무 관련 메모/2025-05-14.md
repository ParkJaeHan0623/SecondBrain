# 📅 2025-05-14 락조회 개념 및 Sequence 정리

---

## 🔒 락조회란?

- **정의**: 현재 테이블 혹은 레코드에 **락(Lock)** 이 걸려 있는지를 확인하는 조회 연계
- **목적**: 다른 사용자가 데이터를 조작하고 있을 때 **동시 처리 충돌 방지**

### 🛠️ 사용 예시
- INSERT, UPDATE, DELETE 같은 **DML 연산**을 수행하기 전에 락이 걸려 있는지 확인
- 락이 걸려 있다면 사용자에게 알려주고 연산을 막음

### ✅ 실무에서는?
- 락조회용 **EBI OP**를 별도로 만들어서 사용하는 경우 많음
- 쿼리 예시:
~~~sql
SELECT *
FROM 테이블명
WHERE 조건
FOR UPDATE NOWAIT;
~~~

## ❗ MAX 함수의 한계

- `MAX + 1` 방식으로 일련번호를 구하는 경우
    
- 여러 사용자가 **동시에 조회하면 중복된 번호**가 발생할 수 있음
    
- 이로 인해 **PK 중복 오류, 데이터 무결성 오류** 발생 가능
    

---

## 🔁 Oracle Sequence 사용하는 이유

- **시퀀스(Sequence)**: Oracle이 제공하는 일련번호 자동 생성 객체
    
- **장점**:
    
    - 중복 없는 유일한 숫자 생성
        
    - 동시 접근에도 **충돌 없음**
        
    - 트랜잭션 간 안전하게 관리됨
        

### 사용 예시:

~~~sql
SELECT 시퀀스명.NEXTVAL FROM DUAL;
~~~
> 보통 INSERT 전에 시퀀스에서 다음 값을 받아와서 PK나 일련번호로 사용함

## 🧠 실무 참고

- 전북은행에서는 **시퀀스 사용에 권한이 필요**하므로 상황에 따라 사용 여부 결정
    
- **데이터 충돌 위험이 있는 경우에는 반드시 Sequence 사용이 권장됨**
