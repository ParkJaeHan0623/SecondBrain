## 🧠 UltraEdit 활용 팁

### 🔹 열 모드 선택

- 단축키: `Alt + C`
- 기능: 텍스트를 **열(Column)** 단위로 드래그 선택 가능
- 활용 예:
    - **로그에서 SQL만 발췌**하고 싶을 때
    - 줄의 같은 위치 열만 복사할 때 매우 유용

## 🛠 실무 마인드셋: “문제 생기면 무조건 로그 먼저!”

- **실행 결과가 이상하거나 데이터가 안 나올 때는**  
    → 무조건 **로그**부터 확인할 것!
- 로그에 나오는 SQL / 값 / Exception이 가장 빠른 힌트
- 흐름을 놓치면 디버깅 시간만 길어짐

---

## 🧾 논리코드에서 로그 찍는 방법

```java
LLog.debug.println("=======로그찍는법출력부분=======", [r로그찍는법출력]);
```

|항목|설명|
|---|---|
|`LLog.debug.println()`|RSA 논리코드 내 로그 출력 함수|
|첫 번째 인자|로그 식별용 문자열|
|두 번째 인자|출력할 DTO or 값|

📍 출력 위치: RSA 로그 창 / 서버 로그 depending on config

## 🧮 SQL 관련 실무 팁

### 🔸 `총건수 조회` vs `목록 조회`

|항목|설명|
|---|---|
|WHERE절|**동일해야 함!** 조건이 다르면 총건수가 다르게 계산됨|
|추천 방식|목록 조회 쿼리 복붙 후 `SELECT COUNT(*)` 만 바꿔서 작성|

---

### 🔸 `NVL(값1, 값2)`

| 항목           | 설명                                    |
| ------------ | ------------------------------------- |
| 기능           | `값1`이 NULL이면 `값2`를 반환                 |
| 예시           | `NVL(고객등급, 'N')` → 고객등급이 없으면 'N'으로 처리 |
| Oracle 전용 함수 | (PostgreSQL에서는 `COALESCE()`)          |

- 텍스트 색, 배경색, 테두리 등 유지하면서 값만 변경할 때 유용
