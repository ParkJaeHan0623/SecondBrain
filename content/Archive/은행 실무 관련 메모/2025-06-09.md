# 📅 2025-06-09 RSA 실무 정리

### ✅ CORA_Ebi 기본 쿼리 제공 흐름

1. `CORA_Ebi` 클릭
2. `Ctrl + Shift + C` → **MDA 코드 생성**
3. 해당 XML 파일 하단에 `tmp` 파일이 생성됨
4. OP를 추가했다면:
    - **기존 tmp 파일 삭제 후** 다시 코드 생성 필요 (변경사항 반영 위함)

---

### ✅ DB 테이블 변경 시 DTO 재생성

> 테이블 스키마가 변경된 경우, DevOn에서 DTO 재생성 필요

경로:

```
Ebi → DTO → DevOnMDA → Model → DTO 생성(DB) → 테이블명 입력
```

 → DTO 자동 생성
