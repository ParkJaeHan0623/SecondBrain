## 🧾 입력/출력 매핑

### 📥 입력 (Input DTO)

- `신한은금융망전문유형코드` → `NBW_MESG_TYCD`

### 📤 출력 (Output DTO)

- `신한은금융망정의식별값`  
  → `NBW_MESG_TYCD || NBW_MESG_VER_NO` (Alias로 결합)

- `신한은금융망서비스식별값`  
  → `NBW_MESG_SVC_ID`

---

## 📌 DTO 구성 기준

- **EBI의 DTO**  
  → *쿼리 결과 기준*으로 **입력/출력 DTO** 직접 설계  
  → SQL과 맞추는 DTO

- **PBI의 DTO**  
  → *MCI*에 맞추기 위한 DTO  
  → 화면과 연결되는 DTO로, MCI와 구조 동일해야 함

- **OP도 마찬가지**  
  → `<<i,ebi>>`와 `<<i,pbi>>`는 각각 역할 다름  
    - `ebi`는 쿼리 중심  
    - `pbi`는 화면 연계 중심

---

## 📋 목록조회 시 주의사항

- `<<i,ebi>>` 목록조회용 OP에는  
  **스테레오타입**에 `paging` 설정 필요  
  (→ 다중성 표기와 함께 `페이징 처리` 자동 적용됨)

---

## 🔢 Oracle Sequence vs MAX

| 항목 | 설명 |
|------|------|
| Sequence | Oracle이 제공하는 자동 일련번호 생성 기능 |
| 사용조건 | 권한 필요, 보통 DBA에게 요청 |
| 현재 상황 | 데이터 적기 때문에 `MAX + 1` 방식으로 처리 중 |
| 주의 | `MAX` 방식은 동시성 이슈가 발생할 수 있음 |

## 🧮 PK 및 기타 컬럼 정리

- `전문정의식별값` = `전문유형코드(PK)` + `전문버전번호(PK)`
- `일련번호` : 불필요 → **삭제**
- `전문적용일자` : 오늘 이후 날짜부터만 허용하도록 조건 설정 필요

## 🧩 RSA 논리코드 구성 팁

### 💡 동기메세지 위치 이동

- `옵션결합단편` → `중요한영역결합단편` 안으로 **드래그**하여 이동 가능

### 🔒 변수 스코프 주의

- `중요결합단편` 안의 코드 블럭은 **자바코드에서 `{}`** 로 묶임  
- 따라서 **변수 선언은 바깥의 `변수선언동기메세지`** 블럭에서 처리해야 함

  - 정보성 컬럼은 읽기전용으로 처리
  - 필수 입력 여부에 따라 스크립트 설정 고려
