## 📌 전문버전내역 단건 조회 최종 쿼리

~~~sql
SELECT 전문정의식별값, 서비스식별값
FROM (
  SELECT  
    전문유형코드 || '.' || TRIM(전문버전번호) AS 전문정의식별값,
    서비스식별값
  FROM 전문버전내역
  WHERE 전문유형코드 = :전문유형코드
    AND 전문적용일자 <= TO_CHAR(SYSDATE, 'YYYYMMDD')
  ORDER BY 전문유형코드 DESC, 전문버전번호 DESC
)
WHERE ROWNUM = 1;
~~~

- `전문정의식별값`: `전문유형코드` + `.` + `전문버전번호` 조합
- `전문적용일자`는 `VARCHAR(8)`이므로 `TO_CHAR(SYSDATE, 'YYYYMMDD')`로 비교
- 최신 적용버전을 1건만 조회 (`ROWNUM = 1`)


## 📌 `isStndCd()` 함수 활용법

### 1. 개념 및 사용법

- **META 코드 유효성 검사 함수**
- 사용 예:
~~~java
LFMdlUtil.isStndCd("CORP_AREA_DIVCD", 지역코드)
~~~
- `true` / `false` 반환
- RSA 논리코드에서는 `[]` 대괄호 안에 필드명을 직접 쓰면 안 됨 → **Java 변환 오류 발생**


---

### 2. 인라인 처리 or LFLocal 사용

#### ✅ 인라인으로 직접 사용 (RSA에서 추천됨)

~~~java
if (LFMdlUtil.isStndCd("CORP_AREA_DIVCD", [i요청].[지역코드]) == false) {   code = "9999";   params = "** 지역코드 오류입니다.";   return; }
~~~
> 단, RSA 변환 시 오류가 발생할 경우 아래 방법으로 우회

#### ✅ LFLocal로 감싸서 처리

~~~java
LFLocal.set("지역코드", [i요청].[지역코드]);  if (LFMdlUtil.isStndCd("CORP_AREA_DIVCD", LFLocal.get("지역코드")) == false) {   code = "9999";   params = "** 지역코드 오류입니다.";   return; }
~~~

## 📌 `offrStndCdInfo()` / `offrStndCdValdtn()`와의 차이

|함수명|기능|사용 목적|
|---|---|---|
|`isStndCd()`|코드 유효성만 체크 (true/false)|**가볍고 빠름**|
|`offrStndCdValdtn()`|유효성 + 코드명 + 상세 정보 반환|화면 표출 or 상세 처리 필요 시|
|`offrStndCdInfo()`|코드 정보 조회 전용|단순 출력용|

## 📌 오류메세지 META

- 위치: `META > 오류메세지 > 표준오류메세지`
- 예외코드: `"9999"`
- 예외메세지: `"지역코드 오류입니다."
