오늘은 **통합단말 화면 개발에서 자주 사용되는 이벤트 함수들**을 정리하고,  
그동안 화면들에서 자주 보였던 함수들을 조사해서 어떤 역할을 하는지 하나하나 익히는 시간을 가졌다.  
부족한 설명이 있던 함수들도 정확한 의미를 찾아서 메모했다.

# 📅 2025-04-16 통합단말 이벤트 함수 정리

---

## 📌 Combo / Control / Grid 관련 주요 함수

|함수명|설명|
|---|---|
|`.AddComboItems("4-테스트;5-테스트")`|콤보박스에 항목을 직접 추가함 (key-value 형식)|
|`.Caption`|해당 컨트롤에 표시되는 문자열 설정/조회|
|`.ChangeComboDataFromFile(instanceCode)`|등록된 코드 콤보 인스턴스 값을 불러와 콤보에 설정|
|`.Clear()`|컨트롤의 데이터를 삭제 (이벤트 포함)|
|`.ClearComboData()`|콤보 컨트롤 내 모든 항목 삭제|
|`.ClearData()`|컨트롤 데이터를 삭제하면서 **이벤트도 함께 발생**|
|`.ClearValue()`|데이터를 삭제하지만 이벤트는 발생시키지 않음|
|`.Data`|해당 컨트롤의 데이터 값을 설정/조회|
|`.DeleteItemByIndex(index)`|콤보박스 항목 중 지정된 인덱스를 삭제|
|`.DeleteItemByKey(key)`|지정된 키 값을 가진 항목 삭제|
|`.DeleteItemByValue(value)`|지정된 항목 값을 가진 항목 삭제|
|`.Enabled`|컨트롤 활성화 여부 설정 / 조회|
|`.GetComboIndex()`|현재 선택된 항목의 인덱스 값 반환|
|`.GetComboKey()`|현재 선택된 항목의 Key 반환|
|`.GetComboValue()`|현재 선택된 항목의 Value 반환|
|`.GetCurIndex()`|선택된 항목의 인덱스를 가져옴 (중복된 의미지만 내부 다를 수 있음)|
|`.GetCurSel()`|선택된 항목의 값(Key/Value 등)을 가져옴|
|`.GetItemCount()`|콤보 항목 개수 조회|
|`Button.Invalidate()`|버튼을 다시 그리는 명령 (겹침 처리 시 유용)|
|`.KeyValidation(row, col)`|지정된 행/열이 콤보일 때 Key 유효성 검사 여부 설정|
|`Combo.Length`|콤보박스 컨트롤의 길이 설정|
|`Grid.DataSaveName(row, "컬럼명")`|행의 특정 컬럼 데이터 이름 설정|
|`Grid.DataRequired(row, "컬럼명")`|해당 컬럼을 필수 입력 항목으로 설정|
|`Grid.DataRows`|현재 그리드의 총 행(row) 수 반환|
|`Combo.setCondition("1-5")`|조건 지정으로 코드 리스트 필터링|
|`Control.SetFocus()`|해당 컨트롤로 포커스를 이동|

## 📌 자주 보이는 단말 이벤트 함수 정리

|함수명|설명|
|---|---|
|`OnInitScreen()`|화면이 최초 로딩될 때 자동 실행되는 초기화 함수|
|`OnClick()`|버튼 클릭 시 실행되는 이벤트|
|`OnEndTran()`|트랜잭션 완료 후 실행되는 후처리 이벤트|
|`OnItemChanged()`|항목 변경 시 실행되는 이벤트 (예: Combo 변경)|
|`OnValidate()`|데이터 입력 후 포커스 아웃 시 실행되는 유효성 검사 이벤트|
|`ClearLinkData()`|연결된 데이터 모두 초기화|
|`getAccDate()`|기준일자(업무일자 등) 가져오는 함수|
|`SetCellFontColor(row, col, color)`|그리드 셀의 폰트 색상 변경|
|`SetCellValue(row, col, value)`|특정 셀에 값 설정|
|`RowCount()`|그리드의 행 개수 반환|
|`setFocus()`|특정 컨트롤이나 셀에 포커스 설정|
|`getByteLength(str)`|문자열의 바이트 길이 반환 (한글 2byte 계산용)|
|`Trim(str)`|문자열의 앞뒤 공백 제거|
|`.Trantype`|트랜잭션 종류 설정 또는 확인 (조회/등록/수정 등)|
|`.Value`|컨트롤의 값 가져오기 또는 설정|

## 🧠 오늘의 깨달음

- “이벤트 함수가 많아 보이지만, 결국 목적은 같음: 사용자 입력을 제어하고 시스템과의 연결을 매끄럽게 하려는 것”
- 하나하나 써보고 해봐야 기억에 남는다. 특히 `OnEndTran()`은 **단말 트랜 종료 후 후처리의 핵심**
