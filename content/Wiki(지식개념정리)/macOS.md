# 5. 사소한 팁

## 5.1 파일 경로 확인법
### ✅ Finder 경로 막대(Path Bar) 켜기

> **Finder 하단에 현재 폴더까지의 전체 경로를 표시**

#### 🔹 설정 방법

1. Finder 열기
    
2. 상단 메뉴 → `보기(View)` → `경로 막대 보기(Show Path Bar)` 체크
    
3. 창 하단에 `/Users/사용자명/문서/예시` 처럼 전체 경로 표시됨

#### 📌 팁

> 폴더를 **오른쪽 클릭 → "정보 가져오기"** 로도 경로 확인 가능
