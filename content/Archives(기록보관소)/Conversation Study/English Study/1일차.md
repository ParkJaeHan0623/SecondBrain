## 🗣️ 영어 프리토킹 연습 요약

### 1. 주제: 업무 소개

#### ✅ 내가 말한 문장

- _I’m working at the bank, and I am a programmer._
    
- _I usually work on fixing Java code._
    
- _I’m working on a system that sends financial messages to other banks._

#### ❌ 교정된 표현

- ❌ _fixing a Java code_  
    ✅ _fixing Java code_
    
- ❌ _systems that sends_  
    ✅ _a system that sends_
    

#### 📚 배운 표현

- _work on ~_ → ~을 작업하다, 처리하다
    
- _financial message_ → 금융기관 간의 전문
    
- _a system that sends ~_ → ~을 보내는 시스템
    

#### 🇰🇷 → 🇺🇸 번역 정리

- “전문을 보내는 시스템” → _a system that sends financial messages_
    
- “문장을 읽고 싶어요” → _Can I get a sentence to read?_

### 2. 주제: 여가 시간

#### ✅ 내가 말한 문장

- _I like to play games with my friends on weekends._
    
- _I like playing Battlegrounds and other FPS games._
    

#### ❌ 교정된 표현

- ❌ _a game with my friends_  
    ✅ _games with my friends_
    

#### 📚 배운 표현

- _FPS (First-Person Shooter)_ → 1인칭 슈팅 게임
    
- _other FPS games_ → “배그 외 다른 FPS들도” 자연스럽게 표현
    
- _Can you say that one more time?_ → “다시 한 번 말해줄래요?”
    

---

### 🔍 전반적인 피드백

- 단수/복수 구분이 약간 헷갈리는 경우가 있었지만, 빠르게 수정하고 적용함
    
- 문장을 완성하려는 의지가 강했고, 반복 연습도 잘 함
    
- 한국어가 나왔을 때도 흐름을 놓지 않고 영어로 자연스럽게 복귀함
    
- **자신감 있게 끝까지 말하는 태도가 아주 훌륭함!**
