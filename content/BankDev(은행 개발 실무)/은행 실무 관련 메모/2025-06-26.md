## 📌 SQLGate for Oracle – 단축키: Ctrl + R

|항목|내용|
|---|---|
|단축키|`Ctrl + R`|
|기능|**검색 후 바꾸기** (Find and Replace)|
|비교|`Ctrl + H`와 동일한 기능 (Visual Studio 등에서의 Replace 단축키)|
|사용 예시|SQL 쿼리 내 특정 키워드 일괄 변경 (ex. 테이블명, 컬럼명 수정)|

🔎 실무 팁:

- 테스트 쿼리 수정할 때, `WHERE 1=1` 같은 조건을 빠르게 일괄 바꿀 때 유용

## 📌 Excel – 보안 걸린 파일에서 값 복사 매크로 설정

### 🔸 상황 설명

- **보호된 시트**에서는 일반적인 `Ctrl + C → Ctrl + V` 가 제한됨
- 수식이나 서식이 붙지 않도록 **"값만 복사"** 하는 기능이 필요함
- 이미 적용된 **`.xlam` 매크로 Add-In**을 활용하여 단축키를 설정할 수 있음

## 📌 VBA란?

|항목|내용|
|---|---|
|정식명칭|**Visual Basic for Applications**|
|역할|Excel(또는 Word, PowerPoint 등 MS Office)의 **자동화** 도구|
|기능|매크로 작성, 반복 작업 자동화, 버튼 클릭 시 로직 실행 등|
|장점|Excel 내부 기능을 세세하게 제어 가능 (UI 조작 포함)|
|사용법|`Alt + F11` 로 편집기 열기, `ThisWorkbook` 또는 `Module` 안에 코드 작성|

## 📌 값 복사 단축키 설정 – 적용된 .xlam 매크로 기준

### 🔧 단축키 설정 절차

1. **`Alt + F11`** → VBA 편집기 진입
2. `현재_통합_문서` 또는 `ThisWorkbook` 클릭
3. 아래 코드 삽입:

```vba
Private Sub Workbook_Open()
    Application.OnKey "^+C", "값복사"
End Sub
```

|항목|설명|
|---|---|
|`^+C`|Ctrl + Shift + C 조합|
|`"값복사"`|호출할 매크로 이름 (기존 매크로와 정확히 일치해야 함)|

> ✅ 위 코드는 파일 열릴 때 자동으로 단축키를 등록함.

---

## 📌 값복사 매크로 예시

```vba
Sub 값복사()
    On Error Resume Next
    Selection.Copy
    Selection.PasteSpecial Paste:=xlPasteValues
    Application.CutCopyMode = False
End Sub
```

|기능|설명|
|---|---|
|`Selection.Copy`|현재 선택된 영역 복사|
|`PasteSpecial xlPasteValues`|값만 붙여넣기|
|`CutCopyMode = False`|복사모드 종료 (회색 테두리 제거)|

## 📋 실무 요약 정리

- **`.xlam`이 이미 적용되어 있다면**, VBA로 단축키 등록만 해주면 된다.
- `Ctrl + Shift + C` 등 커스터마이징 가능
- 시트가 **보호 상태여도 동작 가능** (단, 복사 대상 셀은 잠금 해제 필요)
- `.xlam` 파일은 Excel 실행 시 자동 로딩되므로 **단축키 유지됨**

---

## 🧠 참고 메모

- 시트 보호 상태라도 VBA를 통한 `PasteSpecial`은 동작할 수 있음
- VBA 오류 방지를 위해 `On Error Resume Next`는 권장하지만, **무조건 쓰기보단 예외처리 필요**
