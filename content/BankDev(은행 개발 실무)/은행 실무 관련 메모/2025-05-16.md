# 📅 2025-05-16 전문버전조회 EBI OP 생성

---

## 🧩 업무 개요

부장님이 메시지로 주신 요청:

> **"전문버전조회 Ebi op 생성(쿼리포함)"**  
> 테이블 : 전문버전내역  
> 입력 : 신한은금융망전문유형코드  
> 출력 : 신한은금융망정의식별값(신한은금융망전문유형코드 + 신한은금융망전문버전번호), 신한은금융망서비스식별값

---

## 🔍 내가 이해한 내용

- `전문버전내역` 테이블을 대상으로
- **EBI에서 OP를 하나 생성**
- **조회 OP**는 `전문유형코드`를 입력 받아서
- `정의식별값`, `서비스식별값`을 조회함

---

## 🗃️ 대상 테이블: `전문버전내역 (CPBBO_MSGVR_L)`

| 컬럼명                     | 설명 |
|--------------------------|------|
| 신한은금융망전문유형코드     | 전문 분류 코드 |
| 신한은금융망전문버전번호     | 전문 버전 |
| 신한은금융망서비스식별값     | 연계 서비스 ID |

---

## 🛠️ SQL 예시

~~~ sql
SELECT 
  NBW_MESG_TYCD || NBW_MESG_VER_NO AS NBW_MESG_DEF_ID, -- 정의식별값
  NBW_MESG_SVC_ID                                -- 서비스식별값
FROM CPBBO_MSGVR_L
WHERE NBW_MESG_TYCD = :nbw_mesg_tycd
~~~


---

## ✅ 실무 적용 방식

- RSA에서 `전문버전내역조회` OP를 EBI에 등록
    
- DAO 또는 직접 SQL에 해당 쿼리 등록
    
- OP 결과 매핑 시 `DTO`에 정의식별값/서비스식별값을 매핑
    
- 논리코드에서는 해당 EBI를 호출하여 `입력값 검증`, `중복확인` 등에 사용 가능
