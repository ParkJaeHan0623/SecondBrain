## 📌 eCAMS란?

- **eCAMS**: 형상관리 도구  
    → RSA 내 컴포넌트와 자바 소스 등을 **로컬 ↔ 서버 간 동기화**하는 역할

### 💡 전체동기화 방법

```
JBA_MODEL_VEI_PIC (부대업무) 우클릭 → eCAMS(Z) → 전체동기화
```

- 초기에는 시간이 꽤 오래 걸림
- **JBNgels**도 eCAMS로 동기화 가능 (시간 오래 걸림)

## 📌 DTO 생성 및 명명 규칙

### ▶ 생성 경로

```
JBA_MODEL_VEI_PIC
  └ 모델
    └ 2.시스템명세모델
      └ 03.프로세스컴포넌트
        └ BBO.신한은금융망
          └ 01.신한은금융망전문관리
            └ 09.코드관리
              └ ISO20022전문버전관리Pbi
```

### ▶ 생성 방법

1. `DTO` 우클릭 → `DevOnMDA` → `Model > DTO생성(통합전문IF)`
2. `DTO 클래스 로딩 창`에 전문ID 입력  
    예: `FDCBSBBO_BBO04899111_I`
3. 생성된 DTO → **명명규칙**에 따라 이름 변경

|타입|명명 예시|
|---|---|
|Input|`ISO20022전문버전조회입력Dto`|
|Output|`ISO20022전문버전조회결과Dto`|

## 📌 DtoDm / 더미 DTO 구조

- `DtoDm` = **더미**
- 더미 안에는 여러 개의 DTO 묶음이 들어있음
- 예시:
    - `ISO20022전문버전조회결과Dtodm`
        - `ISO20022전문버전조회결과Dto`
        - `ISO20022전문버전총건수조회결과Dto`

> 더미 안/밖에 있는 DTO 이름을 **동일하게 맞춰야 함**

📌 더미 안의 DTO 추적:

- 우클릭 → `[MDA] 속성 DTO 유형찾기` → 외부 DTO와 매핑

## 📌 OP 구성 및 매핑

- `<<i,pbi>>` 내에 있는 OP들은 기존 거래코드관리에서 복사된 것으로 보임
- 이름만 수정해 사용

### ▶ ServiceID 설정

- OP 클릭 → 하단 **특성 탭**
- `Service_id` 항목에 해당 트랜잭션 ID 입력

### ▶ 매개변수 매핑 방법

- OP 선택 → `Ctrl + OP 클릭` → DTO 선택 → 초록 네모 클릭 (매개변수 유형세팅)
    
- 예시:
    

```plaintext
<<op>> ISO20022전문버전조회()
  → ISO20022전문버전조회입력Dto
  → ISO20022전문버전조회결과Dtodm
```

- 또는 OP 안의 Input/Output 파라미터를 개별 DTO와 매핑
    - 단, 이 경우 더미 안 DTO가 아닌 **외부 DTO와 매핑해야 함**
