# 🔄 퍼블리싱 자동화 및 이미지 동기화 문제 해결 정리

## 1️⃣ 문제 상황 요약

### ❌ Flowershow 퍼블리싱 사용 시 문제점

| 문제 | 설명 |
|------|------|
| 이미지 미반영 | `.md` 파일은 푸시되지만 이미지(`.png`, `.jpg`)는 자동 업로드되지 않음 |
| 이미지 삭제 | 기존 이미지도 `.md` 파일 삭제 시 함께 지워지는 경우 발생 |
| 경로 제어 불가 | 업로드 경로 지정 불가능하여 구조 통제 어려움 |

## 2️⃣ ✅ 선택한 해결 방법: **로컬 파일 동기화 기반 빌드 방식**

### 📦 핵심 전략

- Obsidian 작업 디렉토리: `~/Coding/Obsidian/Blog`
- 퍼블리싱 빌드 디렉토리: `~/Coding/Obsidian/SecondBrain/content`
- Quartz 빌드, Git push까지 자동화 스크립트로 통합
- 이미지 포함 전체 파일을 완벽하게 복사하여 동기화

---

## 3️⃣ 🔁 파일 동기화 스크립트 (rsync + Quartz + Git)

### 💡 사용한 기술

- `rsync`를 통해 Blog 전체 내용을 Quartz `content/`로 복사
- `npx quartz build`로 정적 사이트 생성
- `git push`로 Cloudflare 자동 빌드 트리거

### 📄 `sync-secondbrain.sh` 내용

```bash
#!/bin/bash

echo "🔄 Blog → SecondBrain/content 동기화 시작..."
rsync -av --delete ~/Coding/Obsidian/Blog/ ~/Coding/Obsidian/SecondBrain/content/

echo "🔧 Quartz 빌드 중..."
cd ~/Coding/Obsidian/SecondBrain
npx quartz build

echo "📦 Git 커밋 및 푸시..."
git add .
git commit -m "📝 자동 동기화 및 빌드"
git push origin v4

echo "✅ 완료! 웹사이트에 자동 반영됩니다."
```
