# 🌐 RSA – 연계 전문 처리 시스템

> 은행 시스템에서 외부 기관과의 전문 통신을 담당하는 연계 시스템. 내부 로직과 외부 기관의 메시지 포맷을 연결하고, 송수신 전문을 설계·변환·처리하는 실무 중심 도구.

---

## 1. 🔍 배경

외부 시스템(금융결제원, 한국은행, 신한금융망 등)은 포맷, 프로토콜이 다름.  
→ 내부 시스템(DEVON 등)이 직접 통신하기 어려움  
→ **RSA가 중간에서 전문(Message)을 생성/변환/전송/수신**  

---

## 2. 🧠 개념 요약

| 개념 | 설명 |
|------|------|
| 전문(Message) | 정해진 포맷의 데이터 송수신 구조 (ISO20022, 고정폭 등) |
| RSA | 전문 설계 + 송수신 + 변환(Mapping) + 이력 관리 툴 |
| 연계 로직 | 내부 ↔ 외부 시스템 연결 |
| 연계 트랜잭션 ID (OP) | RSA 내 송수신 단위 식별자 (Operation) |

---

## 3. 🧱 RSA 구성 요소

| 구성요소 | 설명 | 실무 예시 |
|----------|------|-----------|
| AMCD | 연계 업무 단위 컴포넌트 | AMCD_FN_ORG |
| OP (Operation) | 하나의 송수신 전문 단위 | OP_TR_SEND |
| DTO | 전문에 담기는 데이터 구조체 | TR_SEND_DTO |
| Mapping | 내부 데이터 ↔ 외부 전문 매핑 | Inbound / Outbound |
| Header / Body | 전문의 공통(Header), 업무 데이터(Body) 구분 | ISO20022의 AppHdr / Document |

---

## 4. 🛠 실무 흐름 예시

**[송금 업무 흐름]**
1. 단말 클릭 → `setTranID("TR_51620011")`  
2. DEVON 로직 실행  
3. RSA 연계 모듈 호출 (AMCD, OP)  
4. 전문 생성 (DTO + Mapping 기반)  
5. 외부기관 송신  
6. 응답 수신 → 매핑 처리 → DEVON 전달 → 단말 표시  

**[폴더 구조 예시]**
```
AMCD_FN_ORG/
├── PBI_SEND_TR/
│   ├── DTO/
│   ├── OP/ (송신/수신)
│   └── Mapper/ (Inbound / Outbound)
```

---

## 5. ⚙️ 실무 팁: 전문 등록과 매핑

- DTO는 필드명/자료형 정확히 맞춰야 함 (VO와 유사)  
- XML → XPath 매핑 / 고정폭 → 바이트 위치 지정  
- Inbound: 내부 → 외부 전문  
- Outbound: 외부 → 내부 시스템 변환

## [[RSA 구성요소]] 상세 정리

### 🧱 AMCD

| 항목 | 설명 |
|------|------|
| 의미 | 연계 업무 단위 컴포넌트 |
| 역할 | 하나의 연계 모듈 묶음 |
| 예시 | AMCD_ISO_FUND_TRANSFER |

---

### ⚙️ PBI (송신 모듈)

| 항목 | 설명 |
|------|------|
| 의미 | 내부 → 외부 송신 처리 |
| 구성 | 요청 DTO → 매핑 → OP 송신 |
| 예시 | PBI_FUND_SEND |

---

### ⚙️ EBI (수신 모듈)

| 항목 | 설명 |
|------|------|
| 의미 | 외부 → 내부 수신 처리 |
| 구성 | 수신 OP → 매핑 → 응답 DTO |
| 예시 | EBI_FUND_RECV |

---

### 📦 DTO

| 항목 | 설명 |
|------|------|
| 의미 | 전문 송수신에 쓰이는 데이터 구조체 |
| 특징 | VO 형식 (getter/setter) |
| 예시 | DTO_Req_TransferInfo, DTO_Res_ResultInfo |

---

### 🧰 구성 예시

```
AMCD_ISO_FUND/
├── PBI_SendFund/
│   ├── DTO_SendReq
│   └── Mapper_In
├── EBI_RecvFund/
│   ├── DTO_RecvRes
│   └── Mapper_Out
├── OP_TranSend
└── OP_TranRecv
```
