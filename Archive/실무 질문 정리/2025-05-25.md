## ✅ RSA 실무 질문 요약 – SQL 중심 정리

---

### 1. 전문버전조회 단건 조회 SQL (최신 적용일 기준)

#### 🧾 목적

- 입력받은 **전문유형코드**와 **기준일자**를 기반으로
    
- **기준일자 이하 중 가장 최근 적용일자의 1건**을 조회
    

#### ✅ SQL (한글 변수 기준)

~~~ SQL
SELECT
  신한은금융망전문유형코드 || 신한은금융망전문버전번호 AS 신한은금융망정의식별값,
  신한은금융망서비스식별값
FROM 전문버전내역
WHERE 신한은금융망전문유형코드 = :입력한전문유형코드
  AND 신한은금융망전문적용일자 = (
    SELECT MAX(신한은금융망전문적용일자)
    FROM 전문버전내역
    WHERE 신한은금융망전문유형코드 = :입력한전문유형코드
      AND 신한은금융망전문적용일자 <= :조회기준일자
  )
~~~
- `MAX(전문적용일자)` 서브쿼리로 최신 날짜만 골라서
    
- 해당 조건에 맞는 전문버전 1건만 가져옴
    

---

### 2. INSERT vs UPDATE 분기 구조 개념

- 기준 컬럼: `전문유형코드 + 전문버전번호 + 적용일자`
    
- 등록 전에 먼저 `SELECT COUNT(*)`으로 중복 체크
    

#### ✅ 중복 여부 확인용 SELECT

~~~ sql
SELECT COUNT(*)
FROM 전문버전내역
WHERE 신한은금융망전문유형코드 = :입력한전문유형코드
  AND 신한은금융망전문버전번호 = :입력버전번호
  AND 신한은금융망전문적용일자 = :입력적용일자;
~~~
→ 0이면 INSERT, 1 이상이면 UPDATE

---

### 3. INSERT SQL (일련번호 제외)


~~~ sql
INSERT INTO 전문버전내역 (
  신한은금융망전문유형코드,
  신한은금융망전문버전번호,
  신한은금융망전문적용일자,
  신한은금융망서비스식별값,
  한국은행원장상태코드
) VALUES (
  :tx_tp_cd,
  :tx_ver_no,
  :tx_apl_dt,
  :tx_svc_id,
  :bok_st_cd
);
~~~
---

### 4. UPDATE SQL

~~~ sql
UPDATE 전문버전내역
SET 신한은금융망서비스식별값 = :tx_svc_id,
    한국은행원장상태코드     = :bok_st_cd
WHERE 신한은금융망전문유형코드 = :tx_tp_cd
  AND 신한은금융망전문버전번호 = :tx_ver_no
  AND 신한은금융망전문적용일자 = :tx_apl_dt;
~~~

## ✅ 핵심 요약 정리

|항목|내용|
|---|---|
|단건 조회 기준|입력된 전문유형코드 + 기준일자 이전 중 최신 적용일자 1건|
|등록 조건|같은 코드+버전+적용일자가 이미 존재하면 → UPDATE|
|시퀀스 사용|❌ 사용하지 않음 (현업에서 결정됨)|
|적용일자 입력|반드시 “오늘 이후”로 등록 (실무 제약 조건)|
