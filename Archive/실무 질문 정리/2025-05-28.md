## ✅  코드 검증 로직, SQL 활용, RSA 논리코드 오류 대응

### 1. `isStndCd()` 함수 활용 방법 정리

- RSA에서 META 코드 유효성 검증 시 가장 많이 쓰는 함수
    
- `true/false` 반환 (문자열 "false" 비교는 ❌)
    
- 논리코드에서 `[]` 안의 DTO 필드를 함수 인자로 바로 쓰면 RSA → Java 변환 시 오류 발생
    
- 해결책:
    
    - 값을 `LFLocal.set()/get()`으로 넘기거나,
        
    - 중간 변수 없이 바로 인라인으로 넘기되 `[]` 생략 필요
        

### 2. `offrStndCdInfo`, `offrStndCdValdtn`과의 차이점

- `isStndCd()`는 유효성만 검증 (가볍고 빠름)
    
- `offrStndCdValdtn()`은 코드 유효성 + 코드명 등 전체 정보 반환
    
- `offrStndCdInfo()`는 단순 코드 정보 조회용
    
- 이번 로직은 유효성만 필요하므로 `isStndCd()`로 충분함
    

### 3. 코드 유효성 검사 최종 구조 (추천)

```
LFLocal.set("지역코드", [i요청].[지역코드]);

if (LFMdlUtil.isStndCd("CORP_AREA_DIVCD", LFLocal.get("지역코드")) == false) {
  code = "9999";
  params = "** 지역코드 오류입니다.";
  return;
}
```

### 4. SQL 관련 질문들 정리

- `UPDATE`문 예시: 원하는 컬럼만 수정 가능 (SET절에 명시)
    
- `SELECT ... INTO`는 PL/SQL용 문법 (변수 저장용), 일반 SQL에서는 사용 안 함
    
- `WHERE TX_BRCD = CASE WHEN ${tx_brcd} = '0091' THEN TX_BRCD ELSE ${tx_brcd} END`
    
    - 의미: 0091 지점이면 전체조회, 아니면 본인 지점만 조회
