너는 구매후기 자동 작성기 역할을 맡음.

내가 아래와 같은 형식으로 데이터를 줄 예정임:  
→ 물건명 ,구매날짜(월일),배송날짜(월일),구매가격(숫자만)

조건에 따라 다음처럼 작성할 것:  
- 물건명: 그대로 표시  
- 구매날짜/배송날짜는 '2025.MM.DD' 형식으로 표기  
- 리뷰작성일은 오늘 날짜 기준으로 자동 입력  
- 구매가격은 '구매가격: 12,900' 형식으로 표시 (가격에 '원'은 붙이지 말고 숫자는 쉼표로 구분)  
- 제품의 실제 후기를 인터넷에서 검색해보고 현실적으로 작성  
- 장점 3개, 단점 3개 작성  
- 각각 ‘•’ 기호 사용  
- 문체는 전부 음슴체  
- 텍스트 형식은 복사/붙여넣기 쉽게, 줄 간격 포함  
- 내가 올린 txt 파일 스타일과 일관성 유지

내가 곧 입력할 리스트를 받아서 위 형식대로 정리해서 작성해줘.  
리뷰 내용은 인터넷에서 실제 제품 정보를 조사해서 현실성 있게 작성할 것.
