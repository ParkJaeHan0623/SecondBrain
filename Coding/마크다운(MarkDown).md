# 📘 마크다운(Markdown) 개요 및 문법 정리

  

## 1. 🧠 마크다운이란?

마크다운(Markdown)은 **간단한 텍스트 기반 문서 포맷**으로,

별도의 프로그램 없이도 **서식 있는 문서(HTML 등)**를 쉽게 작성할 수 있게 해주는 **경량 마크업 언어**입니다.

  

- 일반 텍스트 에디터로 작성 가능

- GitHub, Obsidian, Notion 등에서 널리 사용

- `.md` 확장자 사용

  

---

  

## 2. 🛠 기본 문법

  

### 2.1 제목 (Headings)

`#`을 사용해 제목 수준을 나타냅니다. (공백 필수)

  

```md

# 제목 1

## 제목 2

### 제목 3

#### 제목 4

##### 제목 5

###### 제목 6

```

  

---

  

### 2.2 목록 (Lists)

  

#### ● 순서 없는 목록

`-`, `*`, `+` 사용 가능

  

```md

- 항목 1

- 항목 2

- 하위 항목

```

  

#### ● 순서 있는 목록

  

```md

1. 첫 번째

2. 두 번째

3. 세 번째

```

  

---

  

### 2.3 강조 (Bold, Italic, 취소선)

  

```md

**굵게**

*기울임*

~~취소선~~

```

  

---

  

### 2.4 링크 (Links)

  

```md

[표시 텍스트](https://example.com)

```

  

---

  

### 2.5 이미지 (Images)

  

```md

![이미지 설명](이미지주소)

```

  

Obsidian에서는 다음과 같은 내부 링크 형식도 사용 가능:

  

```md

![[이미지.png]]

```

  

---

  

### 2.6 코드 (Code)

  

#### ● 인라인 코드

  

\`코드\`

  

#### ● 블록 코드

  

<code>

</code> 또는 언어 지정 가능

  

<pre>

```js

console.log("hello");

```

</pre>

  

---

  

### 2.7 인용문 (Blockquote)

  

```md

> 이것은 인용입니다.

```

  

---

  

### 2.8 구분선 (Horizontal Rule)

  

```md

---

```

  

---

  

### 2.9 체크박스 (Task List)

  

```md

- [ ] 할 일 1

- [x] 완료된 일

```

  

---

  

## 3. 🧩 마크다운 확장 문법 (Obsidian 전용 포함)

  

### 3.1 내부 링크 (Obsidian)

```md

[[다른 노트 제목]]

```

  

### 3.2 폴더 구조 참조

  

```md

[[폴더명/노트명]]

```

  

### 3.3 특수 블록 (Callouts)

```md

> [!note] 노트 박스

> [!warning] 경고 박스

```

  

---
